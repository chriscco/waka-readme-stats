# Workers + D1 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the Worker task; integrate and verify in this session.

**Goal:** Privately collect the user's WakaTime events and publish their coding stats and annual heatmap to GitHub.

**Architecture:** WakaTime clients dual-write to WakaTime and a private Worker. D1 holds events and daily summaries. The existing Python Action reads compatible statistics and an optional SVG.

**Tech Stack:** JavaScript ES modules, Workers, D1/SQLite, Node test runner, Wrangler/Miniflare; existing Python/httpx Action.

## Global Constraints

- Single user; use existing client protocol and existing README formatting.
- Default timezone Asia/Shanghai, idle threshold 15 minutes.
- Private endpoints, bounded validated payloads, retry deduplication, no automatic data deletion.
- AI fields retained; no AI reports. Historical daily totals were approved as a follow-up.
- No deployment or edits to the real client configuration in local development.
