# Personal coding statistics on Workers + D1

Approved scope: reuse WakaTime clients, privately collect coding activity in D1,
retain supplied AI fields, expose daily coding time and language/editor shares,
and produce a green annual SVG heatmap for the existing GitHub README generator.
AI reports are excluded. Historical Insights daily totals were subsequently approved
with their original AI-inclusive totals (see worker/README.md). Default setup is dual
delivery: retain the WakaTime destination and add the Worker through `api_urls`.

## Contract

- Single user, one secret `INGEST_KEY`, no account system or public dashboard.
- Worker lives in `worker/`; use JavaScript modules and Cloudflare D1, no web framework.
- Accept WakaTime single and bulk heartbeat routes under `/api/v1/users/current`.
  Support the client's HTTP Basic credentials and Bearer credentials. Private
  stats also accept `api_key` for the existing README Action's compatibility.
- Bulk responses follow the client's `responses: [[body, status], ...]` protocol.
  Validate timestamps, bounded strings, body size and batch size; acknowledge only
  durable writes. Stable event identifiers make retries idempotent. Preserve
  supplied AI metadata without inventing missing values. Never log secrets or bodies.
- D1 stores normalized heartbeat records and per-day summary caches. Dates use
  Asia/Shanghai (fixed UTC+08:00); the idle threshold is 15 minutes. Time is the gap
  between consecutive events on the same machine when within the threshold;
  isolated events contribute no duration. Overlapping machine intervals count once,
  with deterministic attribution to the most recently started interval. AI app
  thinking events are retained but do not count as foreground coding time.
- Split intervals at local midnight. Recompute affected daily summaries after late
  arrivals, including neighboring dates. Cached results must not mask incomplete
  processing as zero activity. Keep raw records; do not auto-delete history.
- Provide WakaTime-shaped `stats/last_7_days`, `stats/all_time` and
  `status_bar/today` responses, plus private daily totals and SVG heatmap routes.
  Last seven days means the seven completed local dates; all time includes today.
- The annual heatmap contains the most recent 365 local dates ending today, with
  a title, weekday/month labels, green intensity legend and meaningful SVG text.
- Keep the existing Python generator's behavior unchanged unless a new opt-in
  heatmap input is enabled. Save downloaded SVG in assets through existing chart
  handling. On failed heatmap fetch, fail the update instead of replacing with zeros.
- Configuration and docs explain separate plugin and README settings, deployment,
  local tests, D1 export, 500 MB free per-database limit, and dual delivery.
  Never modify the user's real WakaTime configuration or deploy without the account
  being available. Do not include real tokens in files or command output.

## Verification

Test the real Worker with local D1: auth rejection, batch format, invalid input,
retry deduplication, out-of-order/late uploads, idle gaps, midnight boundaries,
multi-machine overlaps, AI metadata retention, compatibility fields and SVG output.
Check the Python heatmap integration using local fixtures without real accounts.
Run a Wrangler dry-run build. Live deployment requires Cloudflare access and remains
distinct from local verification.
